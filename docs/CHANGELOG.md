# 更新日志 · Changelog

倒序记录用户可感知的变化；README 只描述当前状态，历史都在这里。
Newest first; user-visible changes only. The README describes the current state — history lives here.

## 2026-10-11

- 选片彻底重构为上游式纯随机：从今天往前找第一个有达标照片的日子（月-日跨年匹配，
  最多回退一年），当天照片里随机挑；不再轮换、不再冷却，推过的照片随时可能再次
  上屏（含连续重复）。移除 `RECENT_DAY_SPAN` / `RECALL_COOLDOWN_DAYS` 配置项
- 推送单位从「场景」改回单张照片：不再按聚合推封面；相似分叠只用于画廊浏览
  （卡牌堆、挑封面照旧），与推送无关
- 删除推送历史：`push_history` 表与推送计数不再使用（启动时自动清理该表），
  控制台卡片上的「已推送 N 次」与 `/api/pushinfo` 一并移除
- 定时推送「一天一次」的判定改为进程内记忆：推送时刻已过且服务本次启动还没推过，
  就立即补跑；重启服务会重新计时

## 2026-10-09

- 修复今日选片原地踏步：原逻辑从今天往前找第一个有新场景的日子并连着选到榨干，
  场景多的日子会一连多天占据「今日选片」（如 10-06 有 22 个新场景会连推三周）。
  改为在最近 `RECENT_DAY_SPAN`（默认 5）个有可推场景的日子之间轮换，最久没轮到的
  先用——每天换一天；今天有可推场景仍优先今天
- 推过的场景不再永久雪藏：改为冷却 `RECALL_COOLDOWN_DAYS`（默认 60 天，设 0 =
  随时可重推）后重新参与选片，天内在可推场景里随机挑——吸收上游「随机可重推」
  的思路，同时靠轮换避免照片少的日子天天重样

## 2026-10-07

- 相似照片自动分叠：连拍、同场景换姿势聚成一叠（dHash 指纹 + 时间聚类，参数可调）
- 卡牌堆选片：点开一叠拖动或 ← → 翻牌，选中的照片成为这叠的封面并存库
- 场景化推送：一叠算一个场景推封面，推过的场景不再推，每天换新场景
- 画廊：默认筛选「今日选片」，标签多选，筛选状态同步到 URL
- 无限滚动分页，图片按原图比例预留位置，滑动不跳动
