## 2026-10-07

- 相似照片自动分叠：连拍、同场景换姿势聚成一叠（dHash 指纹 + 时间聚类，参数可调）
- 卡牌堆选片：点开一叠拖动或 ← → 翻牌，选中的照片成为这叠的封面并存库
- 场景化推送：一叠算一个场景推封面，推过的场景不再推，每天换新场景
- 画廊：默认筛选「今日选片」，标签多选，筛选状态同步到 URL
- 无限滚动分页，图片按原图比例预留位置，滑动不跳动
